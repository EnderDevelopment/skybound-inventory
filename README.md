# Skybound Inventory

Skybound Inventory is a Minecraft plugin that creates a visually appealing blue inventory with a sky-themed design. This plugin is perfect for servers looking to add a unique and immersive element to their gameplay. The inventory features a blue background with a sun and clouds, providing a serene and calming atmosphere for players.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Open the Minecraft server console or use an in-game command interface.
2. Type the command `/skyinventory` to open the sky-themed inventory.
3. The inventory will appear with a blue background, a sun in the top-right corner, and clouds scattered throughout.
